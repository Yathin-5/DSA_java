## Daily Routine

1. Learn the concept for 1 hour.
2. Solve problems for 1.5–2 hours.
3. Review, write notes, and update progress for 30 minutes.
4. Commit the day's work to GitHub.

## Rule for Every Day

**Topic → Learn the pattern → Solve 3–5 problems → Review → Record progress.**
